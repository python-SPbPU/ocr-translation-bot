# OCRTranslationBot

## Optical Character Recognition

Пример использования:

```python
from ocr.recognition import TextRecognizer

rec = TextRecognizer(
    "sample.png",
    low_threshold=150,  # нижний порог для бинаризации (0-255)
    high_threshold=255, # верхний порог для бинаризации (0-255) 
    clip_limit=30.0,    # ограничение контраста для CLAHE
    tile_grid_size=(8, 8) # размер сетки для CLAHE (строки, столбцы)
)
strings = rec.recognize_text(langs=['ru', 'en'])

for _, text, prob in strings:
    print(f"{text} (вероятность: {prob:.2%})")
```
## Bot Features

Этот бот позволяет обрабатывать изображения с текстом и переводить их. Вот основные этапы работы:

1. **Обработка изображений**
   - Бот принимает изображения, сохраняет их локально и распознаёт текст с помощью `TextRecognizer`.

2. **Выбор языка перевода**
   - После загрузки изображения бот предлагает выбрать направление перевода: с русского на английский или с английского на русский.

3. **Распознавание текста**
   - Использует метод `recognize_text` для распознавания текста на изображении. Поддерживаются языки: русский и английский.

4. **Функция перевода текста в другой язык**
   - Функция принимает распознанный текст, исходный язык, целевой язык, и возвращает переведённый текст.
  Использовалась библиотека `googletrans`, нацеленная на перевод текста с одного языка на другой с помощью Google Translate API.
   - googletrans поддерживает десятки языков;
  
   - В отличие от официального Google Translate API, googletrans не требует регистрации в Google Cloud и получения API-ключа;
  
   - Библиотека поддерживает асинхронные вызовы.
