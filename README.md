## Задача

Разработать функцию перевода текста в другой язык.

## Google Translate Python API

Для выполнения задачи использовалась библиотека `googletrans`, нацеленная на перевод текста с одного языка на другой с помощью Google Translate API.
- googletrans поддерживает десятки языков;
  
- В отличие от официального Google Translate API, googletrans не требует регистрации в Google Cloud и получения API-ключа;
  
- Библиотека поддерживает асинхронные вызовы.


## Установка зависимостей

Перед запуском скрипта, необходимо установить зависимость `googletrans`. Для этого нужно выполнить следующую команду:

```bash
pip install googletrans==4.0.0-rc1
